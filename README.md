Cyber Security Threat Detector

A simple Cyber Security Threat Detector web application built using Python Flask, HTML, and CSS.

The application provides basic checks for common cybersecurity threats such as weak passwords, suspicious phishing links, and potentially dangerous file types.

Features:

- Password Strength Checker
- Checks password length
- Detects passwords containing only letters or numbers
- Identifies common passwords and patterns
-Phishing Link Detector
- Checks for suspicious keywords
- Checks whether HTTPS is used
- Gives a warning for potentially suspicious URLs
- Malware File Checker
- Checks file extensions
- Warns about potentially dangerous extensions such as ".exe", ".bat", ".vbs", and ".scr"
-Simple and user-friendly web interface
-Dark cybersecurity-themed design

Technologies Used:

- Python
- Flask
- HTML
- CSS

1. Install Flask

2. Run the application

python app.py

3. Open in browser

http://127.0.0.1:5000
